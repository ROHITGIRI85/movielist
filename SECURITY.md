# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to the repository owner and include the affected component, reproduction steps, impact, and any suggested mitigation. Avoid accessing data that is not your own while validating a report.

The project owner should acknowledge a report, assess severity, prepare a fix, and disclose details only after users can update safely.

For planned application controls, see [docs/SECURITY.md](docs/SECURITY.md).
